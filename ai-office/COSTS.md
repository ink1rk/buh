# Расходы

Выбран Cursor / grok-4.7, standard, low, 256k; Fast выключен. Учёт провайдера и базового SDK prompt может давать тысячи входных токенов даже для короткого вопроса.

Подтверждены два smoke-ответа (хост и Pod): оценка по токенам $0.010692 и $0.010686 соответственно. Это не фактические списания; диагностические неуспешные попытки до исправления маршрута не имеют подтверждённого token usage/стоимости. Внешний paid billing API вернул feature_unavailable. Проверить реальные списания можно только в Cursor Dashboard.

Производственный ledger usage_costs хранит `billing_state=estimated`. Резерв отдельный в llm_calls: $0.50 на запрос, окно $20/7 суток и $100/календарный месяц; резерв удерживается до окончания окна, в том числе при uncertain. Один вызов за раз, tools=[]; timeout 60 секунд. Это консервативный admission control, а не гарантия непревышения счёта провайдера.

Оценочная формула для стандартного Grok 4.7: input $2/M, cached input $0.50/M, output $6/M; возможные сборы/скидки Cursor и фактическая схема плана сюда не входят. [Источник тарифов модели](https://cursor.com/docs/models-and-pricing).

Новые платные аккаунты/подписки, покупки, платежи или другой LLM-провайдер не подключались. Ресурсы — существующая VM 115; новые PVE VM/storage не создавались.
