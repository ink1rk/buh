# Открытые решения и работы

Требует владельца:

1. Часовой пояс закрыт: Europe/Moscow (UTC+3) записан владельцу. Другую IANA-зону можно задать командой `/timezone`.
2. Календари: Яндекс CalDAV читается (PROPFIND 207). Google выбран, но OAuth Calendar API не передан. Запись в оба календаря ждёт кнопку «Разрешить»; пробное событие не создавалось.
3. Постоянная независимая копия VM/БД. На PVE local доступно около 16.4 GiB, local-lvm — images/rootdir, не backup content. Ежедневные дампы в VM не покрывают потерю её диска. Ручная копия на компьютер проверена.
4. Сверка фактических расходов Cursor: get_usage для аккаунта недоступен. Выбор провайдера/модели уже подтверждён; повторно ключ для него не требуется. LiteLLM поднят без базы и без ключей провайдеров; его `/global/spend` не является счётом Cursor.

Технический backlog:

- Журнал LiteLLM в PostgreSQL: в образе нет Prisma query engine, скачивание engine в под запрещено политикой сети. Пока spend API отвечает `No db connected`.
- Живой specialist Job и loop/failure/recovery. Launcher уже запущен; пробный `/job` не ставился, чтобы не тратить резерв Cursor.
- Google Calendar OAuth. Writer для Яндекса и Google есть; без токена Google исходящий вызов не строится. Почта по-прежнему без writer.
- Живые T01–T15, полное восстановление VM, проверка после reboot, мониторинг/сигнализация, подписи образов.
- Полноценные export/delete и миграционный downgrade. Приём файла и голоса в `stored_files` уже есть; распознавание речи наружу не уходит.
