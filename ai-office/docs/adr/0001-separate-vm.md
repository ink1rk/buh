# ADR 0001 — Отдельная VM, не хост Proxmox

Статус: принято, 2026-10-15.

AI Office ставится в новую QEMU VM `ai-office-k3s-01` (VMID 115) на существующем узле. Диск — `local-lvm`, сеть — тот же мост, что у остальных гостей, без смены firewall датацентра, DNS и reverse proxy.

Профиль: 8 vCPU, 32 GiB RAM, 512 GiB. Образ: Ubuntu Server 24.04 cloud image, контрольная сумма сверяется до импорта. k3s ставится закреплённой стабильной версией, API наружу не публикуется.

Откат VM: остановить и удалить только VMID 115 вместе с её дисками.
