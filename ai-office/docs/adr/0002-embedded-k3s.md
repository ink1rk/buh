# ADR 0002 — Один узел k3s со встроенным datastore

Статус: принято для MVP.

Один узел k3s использует встроенное хранилище. Это не заготовка HA: второй сервер к этому datastore не добавляется. Переход на внешнее HA-хранилище — отдельное решение.

Traefik и ServiceLB выключены, пока нет отдельного решения о входящем веб-доступе. Gateway работает long polling и не открывает webhook.

На установленной версии контроллер network policy v2.6.3-k3s1 стартовал вместе с k3s. Манифесты политик применены. Изоляция считается доказанной только после проверки, что запрещённый исходящий пакет отбрасывается. Проба 2026-10-15 получила `connection refused` и такого доказательства не дала.
