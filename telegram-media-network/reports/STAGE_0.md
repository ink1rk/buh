## Решение о месте кода

Техническое задание описывает отдельный продукт. У этого агента есть право пушить только в подключённый репозиторий `buh`. Код собран в каталоге `telegram-media-network` на ветке `cursor/telegram-media-network-c7b2` от `44ecc03`. Файлы финансового приложения не редактировались.

Память ai-memory в этой среде не найдена. Страница не создавалась.

## Что не трогалось

Proxmox, VM 104, VM 106, VPN, NAT, DNS, файрвол домашней сети, существующие боты и каналы. Живой Telegram не вызывался. Платный API не вызывался. Секреты из чужих `.env` не читались.

## Среда

- Python 3.12, виртуальное окружение `.venv`.
- PostgreSQL 16.15. Служба через systemd не стартовала из-за `policy-rc.d`, кластер поднят `pg_ctlcluster 16 main start`. База `tmn_test`, роль `tmn`, пароль только для локальной проверки.
- Redis на `127.0.0.1:6379` с паролем локальной проверки. Приложение его для доставки не использует.
- Docker 29.1.3 и Compose 2.40.3. Демон сначала не слушал сокет. Позже `dockerd` поднялся, образы собрались. Связность между контейнерами на этой ВМ не заработала, см. этап 6.

- Вместо APScheduler — один advisory lock и тик планировщика.
- Playwright не ставился: снимки страниц источников выключены.
- Dramatiq есть в зависимостях, брокер не запущен. Очередь — таблица outbox.
