## A01. Сборка контейнеров

Статус разделён.

- Файл `compose.dev.yaml` проходит `docker compose config`. Тест `test_a01_compose_file_renders` пройден.
- Образы `tmn-dev-api`, `tmn-dev-scheduler`, `tmn-dev-collector` собрались. Postgres 16.6 и Redis 7.4 скачались. База внутри своего контейнера отвечала на `pg_isready`.
- Готовность API: FAIL. Процесс внутри API не открыл TCP до `db:5432`. Такой же таймаут был у второго контейнера в той же сети. С хоста адрес моста открывался. Причина на этой ВМ — связка veth/bridge, а не пароль и не код приложения. Правила файрвола хоста не менялись. Стек после проверки удалён: `docker compose -f compose.dev.yaml down -v`.

Поэтому A01 целиком не PASS. Приложение проверено на PostgreSQL хоста. Повторить compose нужно на машине, где контейнеры одной сети видят друг друга.
