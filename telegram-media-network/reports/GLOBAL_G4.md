# G4. Пульт

Метка: UNIT TESTED для маршрутов и просмотрено в браузере.

Навигация: Обзор, Радар, Редакция, Календарь, Студия, Источники, Программы, Аналитика, Коммерция, Система. Обзор отличает пустую очередь от отсутствия измерения: слоты считаются по строкам, а «н/д» остаётся для того, что не измерялось.

Путь владельца: обзор → канал в радаре → «В редакцию». Это три перехода. Поиск радара по `CVE` на канале cyber оставляет учебную запись `CVE-2026-990099` со списком `review`.

Календарь хранит UTC и подписывает слот в Europe/Moscow. Перетаскивание и форма зовут сервер. Версия 999 получает HTTP 409 `version_conflict`, строка не переписывается. Это сделано в браузере против живого локального uvicorn и в `test_g5_calendar_does_not_invent_or_publish`.

Ширина 375 не давала горизонтальной прокрутки страницы (`scrollWidth` не больше `clientWidth`). Таблица календаря прокручивается внутри блока. Скриншоты: `overview-1280.png`, `overview-375.png`, `radar-1280.png`, `radar-375.png`, `editor-1280.png`, `editor-375.png`, `calendar-1280.png`, `calendar-375.png`.

Анонимный `POST /api/v1/demo/load` — 401, редактор — 403, владелец — 200. Включение рекламы владельцем — 403. `test_g4_pages_and_routes`.
