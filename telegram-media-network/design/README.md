# Визуальные референсы

- `user_reference_vps_audit.png` и `user_reference_awesome_re.png` — изображения **предоставлены пользователем** в качестве примера того, как в Telegram выглядят публикации с описаниями GitHub-проектов. Это референс UX, **не материал для повторной публикации или копирования брендов**.
- `card_demo.png` — **полностью синтетический пример**, созданный для данного пакета; вымышленный проект и текст, никогда не публиковать в живой канал.
- `card_template.html` — статический собственный пример дизайна 1280×720. Cursor должен разработать реальный динамический шаблонизатор и проверить переносы, кириллицу и размер Telegram caption.

Рекомендуемый итог: один image thumbnail/cover 16:9 + текст Telegram под ним и источник. Не пытаться «сфотографировать» всю подпись на карточку: на телефоне это будет мелко.
