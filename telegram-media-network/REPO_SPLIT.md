# Перенос в отдельный репозиторий

Этот файл только описывает перенос. Каталог не перемещается и новый репозиторий не создаётся, пока владелец не разрешит это отдельно.

Сейчас код лежит в `ink1rk/buh/telegram-media-network`, потому что агент может публиковать только подключённый репозиторий `buh`. Финансовое приложение в этом переносе не участвует: у каталога нет общих модулей, миграций и настроек с остальным деревом.

## Что переносить

- Каталог `telegram-media-network` целиком, включая `app`, `tests`, `alembic`, `configs`, `schemas`, `reports` и `requirements*.txt`.
- История коммитов, которая касается только этого каталога. История финансового приложения не нужна.

## Что не переносить

- Секреты, `.env`, `.venv`, `var/` и локальные базы.
- Токены действующих ботов и любые файлы VM 104, VM 106 и Proxmox.

## Куда

Отдельный репозиторий с именем `telegram-media-network`. Первая ветка — `main`. Доступ на запись остаётся у владельца. Этот агент пуш туда не делает.

## Проверка после переноса

Чистый checkout, `docker compose config`, `alembic upgrade head` на пустой базе и `pytest`. Пока контейнеры на этой машине не видят Postgres, этап A не считается пройденным и в новом репозитории тоже.
