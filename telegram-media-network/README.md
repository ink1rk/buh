# Telegram Media Network

Локальный редакционный контур для восьми русскоязычных каналов. Эта сборка работает в режиме dry-run: она готовит карточку и подпись, пишет аудит и не отправляет запросы в Telegram.

Проект лежит в каталоге `telegram-media-network` репозитория `buh`, потому что у этого агента нет права создать отдельный репозиторий. Файлы финансового приложения не менялись.

## Что умеет

- Восемь каналов из `configs/channels.yaml`, все с `publish_enabled: false`.
- Офлайн-разбор публичных фикстур GitHub, Hacker News, arXiv, CISA KEV, RSS, Hugging Face, PyPI и Cloudflare. Живой опрос включается только `SOURCE_MODE=live` и ходит через allowlist; по умолчанию сборщик сеть не открывает.
- Дедуп, маршрут в один основной канал, оценка rubric-v1 и детерминированный редактор. `LLM_MODE=local` требует явный URL и инъекцию клиента; в этой сборке живой Ollama не вызывается, тесты идут через FakeOllama. Платный LLM не вызывается. Отказ модели возвращает шаблон. Пилот только `offline_replay`.
- Карточка 1280×720 своим шрифтом DejaVu, с пометкой «СВОЙ МАКЕТ». Чужое превью не подставляется без права `licensed_reuse`. Пустая фотография в отправку не попадает.
- Очередь публикации, один лидер на advisory lock Postgres, сверка неоднозначной отправки.
- Русская админка на `127.0.0.1:8787`: обзор, радар, редакция, календарь, студия, источники, программы, аналитика, коммерция, система.
- Офлайн-пакет DEMO: кластеры и объяснимый счёт, черновики с тремя углами, четыре макета студии, предложенный календарь на 14 дней, измеренная воронка и две учебные кампании. Кнопка загрузки есть только у владельца. Пакет не читает сеть и не публикуется. Флаги `FEATURE_*` открывают эти экраны и не меняют `SOURCE_MODE` или отправку.

Отправка в Telegram возможна только если одновременно выключен dry-run, включены общий и канальный флаги публикации, снят kill switch и канал не на паузе. Транспорт создаётся только при `TELEGRAM_TRANSPORT=sandbox` и этих же условиях плюс тестовый токен и chat id. Без этого разрешения он остаётся `None`, и `DRY_RUN=true` не открывает сеть. В outbox уходит JPEG связанной карточки; если карточки нет, запись уходит в повтор, а транспорт не вызывается.

В `compose.dev.yaml` схему поднимает отдельный сервис `migrate` и завершается до API и воркеров. Они только проверяют ревизию (`TMN_SCHEMA=check`). Тесты по-прежнему создают таблицы напрямую. Карточки пишутся в общий том. Запись `StoryEvidence` при разборе получает статус `extracted` и пустое `verified_at`: автоматический разбор не считается независимой проверкой. `SOURCE_MODE` в поставляемом окружении остаётся `offline`.

`GITHUB_READ_TOKEN` уходит только на `api.github.com` и `github.com`. `HF_READ_TOKEN` уходит только на `huggingface.co`. Междоменный редирект не выполняется, поэтому токен одного сервиса не попадает в запрос к другому. Публичные API Hugging Face работают и без токена. `LLM_BASE_URL` — это корень локального Ollama, а путь по умолчанию `/api/chat`. Разрешены только хосты из `LLM_ALLOWED_HOSTS`, по умолчанию loopback. `/health/ready` отвечает только за базу. Состояние воркеров смотрит владелец в `/health/components`.

## Запуск проверок

Нужны Python 3.12, PostgreSQL 16 и локальная роль. В этой среде база `tmn_test` принадлежит роли `tmn` с паролем `tmn_test_only`. Это пароль только для локальной проверки.

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/pytest
.venv/bin/ruff check app tests
.venv/bin/mypy app
```

Админка на уже поднятой базе:

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8787
```

Учётная запись создаётся отдельно. В интерфейсе у владельца видны значки DRY RUN и KILL SWITCH. Кнопка «Предпросмотр отправки» не открывает соединение с Telegram.

`compose.dev.yaml` публикует только `127.0.0.1:8787`. У Postgres и Redis нет портов на хосте. На этой виртуальной машине контейнеры одной сети не устанавливают TCP друг с другом, поэтому полный `docker compose up` здесь не становится готовым. Подробности в `reports/STAGE_6.md`.

## Чего здесь нет

Продакшен-запуск запрещён кодом: `ENVIRONMENT=production` останавливает старт. Нет живого бота, нет канала, нет правок Proxmox, VM 104, VM 106, VPN, NAT, DNS и файрвола. Канареечная отправка (G6) и ввод в прод (G7) заблокированы. Запрос на будущую машину лежит в `PRODUCTION_APPROVAL_REQUEST.md` и на этом останавливается.

Рекламный контур выключен. Пост с пометкой спонсора не подтверждается без отдельной кампании и юридической отметки. Просмотры Telegram не выдумываются: в статистике стоит «н/д», пока нет ручного замера.
