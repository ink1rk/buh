# Запрос на допуск к продакшену

Это запрос, а не разрешение. Код при `ENVIRONMENT=production` не стартует. Ниже нет VMID, IP-адреса, токена и идентификатора канала. После этого файла работа останавливается: канареечная отправка и ввод в прод не выполняются.

## Что нужно от владельца

1. Новая виртуальная машина Ubuntu 24.04, отдельная от VM 104 (Home AI Hub) и VM 106 (GitLab). Ориентир по размеру: 4 vCPU, 8 ГБ памяти, 60 ГБ диска, без GPU. Имя, VMID, адрес и сеть назначает владелец. Существующие ВМ, Proxmox, VPN, NAT, DNS, файрвол и резервные копии не меняются.
2. Админка слушает только `127.0.0.1:8787`. Снаружи порт не открывается. Postgres и Redis тоже не публикуются на хост.
3. Новый бот, не тот, что уже используется. Токен передаётся по имени переменной `TELEGRAM_BOT_TOKEN`, не через чат и не через git. Идентификаторы каналов владелец записывает сам, когда решит их создать. Эта сборка каналы не создаёт.
4. Первые 14 дней — только ручное подтверждение. Автопубликация остаётся выключенной. Для КиберРадара и материалов CVE нужны два разных человека, второй — REVIEWER_SECURITY или OWNER.
5. Реклама выключена, пока нет отдельного юридического согласования и маркировки.
6. Модель остаётся mock. Локальный LLM можно подключить позже только явным `LLM_MODE=local` и отдельным URL, который владелец одобрит. Платный API не предполагается.
7. Перед включением нужен успешный учебный restore из зашифрованного дампа на чистую базу и подпись человека на отчёте пилота. Программа подпись не ставит.

## Что остаётся заблокированным

- G6, канареечная отправка во временный канал: BLOCKED. Нет разрешения и нет временного токена.
- G7, продакшен: BLOCKED. Нет утверждённой ВМ, сети, бота, списка каналов и политики рекламы.

Дальше этот репозиторий сам ничего не включает.
