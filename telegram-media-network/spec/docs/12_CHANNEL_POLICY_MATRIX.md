# 12. Редакционная политика по восьми каналам

## НейроПульс / Новости AI

**Да:** официальные новые модели, API/релизы, исследования с реальным новостным поводом, изменения доступа, опубликованные сравнительные тесты с корректной методологией. **Нет:** слухи с анонимных X-аккаунтов как факты, несуществующие версии GPT, бездоказательные «победы» одного вендора, реклама без маркировки. Источники: HF, arXiv, официальные публикации через контролируемый RSS и HN как discovery. Приоритет: важность+достоверность.

## AI Инструменты / Полезные нейросети

**Да:** работающие демо-приложения, полезные репозитории, selfhosted AI с заявленными requirements, конкретные возможности и лицензии. **Нет:** «бесплатно» при 2-дневном trial, автоматическая регистрация/скачивание, непроверенные опасные установщики, кликбейт, генерация fake benchmark. Проверять pricing/free tier в первоисточнике.

## GitHub Находки / Бесплатный Open Source

**Да:** утилита с понятным purpose, живым repo, release notes, документированная OSS-лицензия, реальная практическая польза. **Нет:** empty README, звёзды без новизны, archived репозитории без причин, public no-license, malicious/dual-use без отдельного security review. Пост: проект, 3 функции, кому полезен, поддерживаемые платформы/лицензия если подтверждены.

## КиберРадар / Информационная безопасность

**Да:** CISA KEV, официальные advisories, defensive patch guidance, выявленные риски и необходимые защитные шаги. **Нет:** незаверенные CVE-scoring, эксплуатационные PoC, фишинг, инструкции обхода защиты, «взломали всех» без источника. **Обязательно:** second human reviewer, verified affected versions, ни одной автоматической emergency публикации.

## ИнфраХаб / Системное администрирование

**Да:** Kubernetes и Linux релизы, сетевые/серверные практики, CVE fixes с verified vendor guidance, мониторинг, backup/restore, IaC. **Нет:** применение несовместимых команд без disclaimer или test, публикация внутренних IP/секретов, советы ломать прод.

## HomeLab / Домашние серверы

**Да:** Proxmox, TrueNAS, Docker, Home Assistant, безопасный self-hosted софт, энергоэффективность, сетевые рецепты на домашнем стенде. **Нет:** публикация опасных WAN-портов как обязательного шага, инструкции по пиратству, ненадёжные скрипты установки, рекламные закупки без disclosure.

## DevPulse / Разработка

**Да:** языки/фреймворки, AI coding tools, CI/CD, автоматизация, измеримые улучшения dev workflow. **Нет:** копии changelog без контекста, «доступная всем» премиум функция без проверки, breaking changes без версии.

## ТехноЗавтра / Наука и технологии

**Да:** новые результаты исследований, роботы, полупроводники, космос, необычные устройства, опубликованные эксперименты. **Нет:** «технология готова на рынок» по одной концепции, преувеличения, фантазии, замаскированные под новости. Препринт обозначать явно; про эксперименты писать с ограничениями и датой.

## Внутрисетевой конфликт и повтор

Один и тот же первоисточник может быть виден нескольким каналам, но решение о публикации должно учитывать **story cluster** и самое ценное объяснение для аудитории. Вместо автокросспоста — назначить primary. Второй post допустим только при новом факте/уникальной инструкции, после 48h или отдельного OWNER override и аудита.
