# Telegram Media Network — единый пакет ТЗ для Cursor

**Версия:** 1.0 · **Дата:** 10.11.2026 · **Язык:** RU · **Статус:** ТЗ к реализации, НЕ развёрнутая система

## Что строим

Один управляемый движок восьми Telegram-каналов: сбор открытых данных из первоисточников, нормализация, проверка/ранжирование, редактор на LLM, создание карточек, очередь модерации и публикация с измеримым результатом. Источники бесплатны для доступа в рамках их правил. Платные API и реклама **не обязательны**.

**Каналы:** НейроПульс, AI Инструменты, GitHub Находки, КиберРадар, ИнфраХаб, HomeLab, DevPulse, ТехноЗавтра.

## Начни здесь в Cursor

1. Прочитай **`CURSOR_START_HERE.md`** целиком: там порядок работ, запреты, критерии остановки.
2. Прочитай **`docs/01_MASTER_TZ.md`** — обязательные требования (FR/NFR), границы проекта, допущения.
3. Затем `docs/02_ARCHITECTURE.md`, `docs/03_SOURCES.md`, `docs/04_EDITORIAL.md`, `docs/05_CARDS.md`, `docs/06_OPERATIONS.md`, `docs/07_SECURITY_LEGAL.md`, `docs/08_MONETIZATION.md`, `docs/09_ACCEPTANCE.md`, `docs/10_ADMIN_UI.md`, `docs/11_DEPLOYMENT.md`, `docs/12_CHANNEL_POLICY_MATRIX.md`.
4. В `configs/` — **пример** настроек, не вводить реальные токены в репозиторий.
5. В `schemas/`, `prompts/`, `examples/` — контракты данных и редакторские правила.
6. В `checks/` — инструкция о доказательствах прохождения каждого gate.

## Важные границы

- Пользовательский **Proxmox VE не трогать до отдельного разрешения**: не создавать VM, не менять firewall/NAT/WireGuard, сети, хранилище, бэкапы и существующие VM.
- VM 104 Home AI Hub и VM 106 GitLab — живые системы; не перезапускать, не обновлять и не использовать как тестовый стенд без подтверждения. История миграции памяти/изоляции RAG не закрыта. Не включать писателя ai-memory и не делать cutover.
- Не переиспользовать существующий Telegram bot token: только после отдельного разрешения; не нарушать webhook/getUpdates чужих сервисов.
- Все публикации `DRY_RUN=true`, пока не согласованы адреса каналов, права бота, правила контента и администратор не разрешил production.
- Реклама и коммерческое размещение остаются выключенными до юридической проверки на дату публикации.

## Критерий готовности

Нужен **работающий код и доказательства тестов** по контрактам этого пакета, а не только дизайн. Команды и логи сохранять в `reports/` созданного Cursor репозитория, **секреты маскировать**. Сообщение «всё готово» без отчётов по acceptance — не принимается.

## Об официальных справочниках

Ссылки и ограничения источников — по состоянию на 10.11.2026 и должны **перепроверяться агентом перед production**. Интернет-источники доступны без лицензии на автоматическое перепечатывание текста и изображений: система публикует оригинальные краткие аннотации с ссылками, а не копии материалов.
