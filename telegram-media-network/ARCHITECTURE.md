# Архитектура

Один процесс FastAPI хранит редакцию. Сборщик и планировщик — отдельные процессы с той же базой. Транспорт Telegram подключается только через `build_telegram_transport`, и в обычном запуске он равен `None`.

Поток материала: фикстура или будущий разрешённый HTTPS-источник → проверка схемы → ключи идентичности → один основной канал → оценка → текст редактора → карточка → ручное подтверждение → запись в outbox. Dry-run возвращает предпросмотр до любого HTTP-клиента Telegram.

## Замены, которые прямо названы

- Планировщик — не APScheduler. Один процесс держит `pg_try_advisory_lock(8787001)` на соединении с AUTOCOMMIT и раз в минуту вызывает `scheduler_tick`. Второй процесс блокировку не получает и ничего не ставит в очередь.
- Dramatiq указан в зависимостях. Живой брокер не используется: доставка идёт синхронно через outbox и внедрённый транспорт, чтобы тест мог доказать отсутствие сети.
- Playwright не установлен. `screenshot_enabled` и удалённые OG-картинки выключены. Карточка рисуется Pillow и шрифтом DejaVu.
- Редактор по умолчанию детерминированный. `LocalLLMClient` ходит только на URL из настройки и принимает ответ, если он проходит `schemas/post_draft.schema.json`. Поле `publish` и `requires_review: false` отбрасываются. Исходный текст передаётся в `source_data` и не считается инструкцией. `auto_approve_allowed()` всегда возвращает ложь.

## Границы отправки

`Policy.network_allowed` истинен только когда dry-run выключен, публикация включена, kill switch снят, у канала включена публикация и канал не на паузе. Даже тогда `publish_preview_or_send` требует владельца и подтверждение. Ответ 401/403 ставит канал на паузу. Ответ 429 ждёт ровно `Retry-After`, но не меньше одной секунды. Таймаут после отправки и обрыв до записи `published_messages` переводят запись в `needs_reconciliation`. Повтор сам не уходит.

Идемпотентность — `sha256(channel|post|draft_version|publish_intent_id)`. Частичный уникальный индекс не даёт двум активным записям outbox висеть на одном посте и канале. Захват идёт через `FOR UPDATE SKIP LOCKED`.

## Сеть источников

Живой опрос выключен (`SOURCE_MODE=offline`). В этом режиме `collect_once` пишет здоровье источника `offline` и не вызывает HTTP. При `SOURCE_MODE=live` тот же цикл берёт URL из конфигурации источника, проходит `safe_get` и сохраняет ETag, ошибку авторизации, лимит и открытый контур после пяти неудач. Повторный разбор того же материала не создаёт вторую запись. `assert_url_safe` пускает только https и список хостов, запрещает литералы частных, локальных, link-local, CGNAT и метаданных адресов и перепроверяет каждый редирект. Cloudflare остаётся выключенным, пока нет точного адреса ленты.

## Данные

Тесты создают схему через `create_all`. Запуск с `TMN_SCHEMA=migrate`, включая `compose.dev.yaml`, вызывает `alembic upgrade head` и не прячет изменение схемы в `create_all`. Секреты в таблицу не пишутся: есть только ссылки вида `env:TELEGRAM_BOT_TOKEN`. Пароли пользователей хранятся как Argon2id. Сессия — это хэш cookie `tmn_session`, плюс отдельный CSRF-заголовок. Доказательство из источника хранится как `extracted`; `verified_at` заполняется только после отдельной проверки, которой в этом контуре нет.
