# R9 UX flow

Оператор работает в одном центре управления сетью. Публикация выключена.

1. Вход → **Обзор**: восемь редакций, очередь, пустые дни на 28 суток, «н/д» вместо выдуманной аудитории.
2. **Радар**: карточки тем, роль источника, 2–3 строки «почему», фильтр канала/списка, объединить/разделить.
3. **Редакция**: inbox форматов, материал с claims, QA-блоком, версиями и предпросмотром подписи.
4. **Календарь**: 7/28 дней, proposed ≠ scheduled, lock и перенос с версией.
5. **Студия**: 5 композиций × 8 каналов, JPEG 1280×720, знак DEMO.
6. **Источники**: роль и вес доверия, живой опрос выключен.
7. **Качество**: блокирующие нарушения, stale-карточки, непроверенные claims.
8. **Рост**: воронка по lineage, 0 vs н/д vs DEMO, эксперименты NOT_STARTED.
9. **Коммерция**: пайплайн, пакеты без цены, медиакит с аудиторией «пока не измерены».
10. **Система**: флаги fail-closed, экспорт без секретов, sponsored switch отклоняется.

Адаптив: 375 / 768 / 1280 / 1600. Тёмная тема. CSRF и роли без изменений.
