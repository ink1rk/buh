# Obsidian

Сервер MCP `notes`. Vault — источник памяти. Не пиши заметки мимо него.

- `notes_search` — найти по фразе. Перед ответом «я этого не помню» сначала поиск.
- `notes_write` — записать. По умолчанию папка `00 Inbox`.

Папки vault: `00 Inbox`, `01 Daily`, `02 Finance`, `03 People`. В заметку клади факт, который владелец просил сохранить, без пересказа всей переписки.
