# Политика отдела технической инфраструктуры

Генератор многостраничного PDF-документа «Политика отдела технической инфраструктуры»
(24 раздела + 20 приложений с формами для заполнения, схемы, диаграммы и таблицы).

## Сборка

```bash
pip install reportlab matplotlib
python3 generate_policy.py            # соберёт PDF в текущий каталог
python3 generate_policy.py out.pdf    # или в указанный файл
```

Результат: `Политика_отдела_технической_инфраструктуры_v1.0.pdf` (114 страниц).

## Проверка вёрстки

```bash
python3 check_layout.py               # переполнение текста в схемах
python3 check_pages.py                # висячие заголовки в готовом PDF
python3 preview.py                    # контактные листы страниц в build/preview/
```

## Состав

| Файл | Назначение |
| --- | --- |
| `generate_policy.py` | точка входа: собирает диаграммы и PDF |
| `builder.py` | вёрстка: шрифты, шаблоны страниц, колонтитулы, таблицы, формы, оглавление |
| `charts.py` | 33 схемы и графика (matplotlib) |
| `content_main.py` | титул, служебные листы, разделы 1–4 |
| `content_core.py` | разделы 5–11 |
| `content_ops.py` | разделы 12–17 |
| `content_final.py` | разделы 18–24 и приложения A–T |
| `preview.py` | служебный рендер страниц в PNG для проверки вёрстки |
| `check_layout.py` | проверка схем: текст не выходит за границы блоков и не перекрывается |
| `check_pages.py` | проверка готового PDF: нет заголовков, оставшихся внизу страницы без текста |

Шрифты подбираются автоматически из числа установленных в системе
(Inter → Noto Sans → DejaVu Sans → Liberation Sans) — все с поддержкой кириллицы.

## Что нужно заполнить перед утверждением

- реквизиты на титульном листе и лист согласования;
- классы критичности и владельцев сервисов в реестре (приложение B);
- целевые значения RPO/RTO, окна работ, пороги ёмкости;
- Technology Standard с разбивкой по подразделениям (раздел 17);
- SLA и KPI — отдельными документами (раздел 20).
