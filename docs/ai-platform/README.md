# Схема архитектуры ИИ-платформы

Перерисованная версия схемы: те же компоненты и связи, но с послойной
компоновкой, подписанными связями и легендой.

## Сборка

```bash
pip install matplotlib
python3 architecture.py
```

Скрипт кладёт рядом с собой три файла:

| Файл | Для чего |
| --- | --- |
| `Архитектура_ИИ-платформы.png` | вставка в презентации и переписку |
| `Архитектура_ИИ-платформы.svg` | правка в Figma, Inkscape, draw.io |
| `Архитектура_ИИ-платформы.pdf` | печать и вложение в регламенты |

## Что изменилось по сравнению с исходной схемой

Смысл и состав элементов сохранены полностью, изменена подача:

- **Слои вместо свободного размещения.** Шесть горизонтальных полос с
  подписями слева: пользователи, точки входа, рабочие среды, слой моделей,
  шлюз интеграций, MCP-серверы и целевые системы. Поток читается сверху вниз
  без пересечения линий.
- **Значки заменены словами.** `R` / `RW` превратились в «права: чтение» и
  «права: чтение и запись», `global` / `local` остались как подписи на
  связях, но расшифрованы в сноске под схемой.
- **Видна граница периметра.** Внешние сервисы (Grok, ChatGPT, HR Box,
  HR-Link, Planfix, MCP на стороне поставщика) выделены цветом и пунктиром,
  внутренние компоненты — сплошной заливкой.
- **Единый вход раскрыт явно.** Учётная запись Active Directory с 2FA даёт
  доступ сразу ко всем средам кластера, а `CLI + API-ключ` показан как
  отдельный сервисный путь в обход рабочих сред.
- **MCP-серверы названы по целевым системам.** Вместо четырёх одинаковых
  прямоугольников `MCP` — `MCP · 1С`, `MCP · Express`,
  `MCP · Active Directory`, `MCP · Git`, каждый над своей системой.
- **Каждый блок поясняет сам себя.** У компонентов есть короткая строка
  назначения, поэтому схему можно читать без сопроводительного текста.

## Правка

Вся геометрия собрана в константах в начале `architecture.py`: палитра,
границы холста `X0/X1/Y0/Y1`, список слоёв `BANDS`, состав рабочих сред
`ENVS`, колонки интеграций `INTEGRATIONS`, легенда `LEGEND` и сноска
`FOOTNOTES`. Единица координат равна 0.1 дюйма по обеим осям, поэтому
скругления и окружности не деформируются при изменении размеров.

Проверить компоновку после правок:

```bash
python3 architecture.py   # падений быть не должно, файлы перегенерируются
```
